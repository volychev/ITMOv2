# Proposal

## Why

`rubrica` выдаёт отчёт только в stdout. Человеку, который смотрит сдачу, неудобно
читать длинный текстовый список в терминале, а JSON не предназначен для глаз.
Нужен автономный файл, который можно открыть в браузере, отправить коллеге или
приложить к сдаче.

## What Changes

- Новый флаг `rubrica <target> --html PATH` сохраняет один самодостаточный
  HTML-отчёт: вердикт, баллы, счётчики, все находки, предупреждения и состояние
  рецензии.
- Совместимость с `--json`: stdout остаётся прежним чистым JSON, путь к файлу
  печатается в stderr.
- `--max-findings` продолжает ограничивать только текстовый stdout; в HTML
  попадают все находки.
- В браузере доступны поиск, фильтр severity, «только провалы», сортировка и
  сброс. Без JavaScript страница остаётся полной.
- Путь проверяется до аудита: расширение `.html`/`.htm`, существующая
  родительская папка, не каталог и не symlink. Запись атомарная, права `0600`.
- Ошибка пути или записи возвращает код 2 и приоритетнее кода 3.

## Capabilities

### New Capabilities

- `html-report`: автономный HTML-отчёт аудита и его интерактивные фильтры.

### Modified Capabilities

Нет: поведение существующих возможностей не меняется, `--html` только добавляет
побочный артефакт.

## Impact

- `src/rubrica/report_html.py` — новый модуль.
- `src/rubrica/cli.py` — новый флаг и вызов экспорта.
- `tests/test_report_html.py`, `tests/test_cli_html.py` — новые проверки.
- `docs/requirements.md`, `README.md`, `AGENTS.md` — описание контракта.
- Новых зависимостей нет: только стандартная библиотека и inline CSS/JS.
