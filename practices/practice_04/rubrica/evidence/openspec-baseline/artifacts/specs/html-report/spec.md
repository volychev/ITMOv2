## Purpose

Автономный HTML-отчёт даёт человеку читаемый результат аудита `rubrica` в одном
файле, который открывается без сети и позволяет быстро найти нужную находку.

## ADDED Requirements

### Requirement: Экспорт HTML по флагу `--html`

CLI SHALL сохранять автономный HTML-отчёт, когда передан `--html PATH`.
Флаг MUST быть совместим с `--json` и `--max-findings`; stdout MUST оставаться
прежним, а подтверждение пути MUST печататься в stderr.

#### Scenario: Успешный экспорт

- **WHEN** запускают `rubrica <target> --html report.html`
- **THEN** файл `report.html` создан, код возврата совпадает с кодом аудита,
  stdout содержит обычный отчёт, а stderr — `HTML-отчёт: <абсолютный путь>`

#### Scenario: JSON и HTML одновременно

- **WHEN** запускают `rubrica <target> --json --html report.html`
- **THEN** stdout — валидный JSON прежней схемы без поля `html`, а файл создан

### Requirement: Полнота отчёта

HTML SHALL содержать вердикт, баллы, счётчики, все находки, предупреждения и
состояние рецензии. `--max-findings` MUST ограничивать только текстовый stdout.

#### Scenario: Лимит не режет HTML

- **WHEN** передают `--max-findings 1` при шести находках
- **THEN** stdout скрывает лишние правила, а в HTML присутствуют все шесть

### Requirement: Интерактивные фильтры

Отчёт SHALL предоставлять поиск, фильтр severity, «только провалы», сортировку
и сброс. Фильтры MUST комбинироваться по AND, а счётчик MUST показывать число
видимых находок.

#### Scenario: Поиск и фильтр

- **WHEN** вводят `readme`, выбирают `blocker` и включают «только провалы»
- **THEN** остаются только проваленные находки severity `blocker`, совпадающие
  с запросом, а счётчик показывает `Показано N из M`

#### Scenario: Сброс

- **WHEN** нажимают «Сбросить»
- **THEN** поиск пуст, severity `все`, чекбокс выключен, сортировка —
  «порядок рубрики», и видны все находки

#### Scenario: Пустой результат

- **WHEN** поиск не совпадает ни с одной находкой
- **THEN** показывается «Ничего не найдено…», счётчик равен `Показано 0 из M`,
  а метрики шапки не меняются

### Requirement: Работа без JavaScript

Отчёт SHALL оставаться полным и читаемым без JavaScript. Панель фильтров MUST
быть скрыта, если скрипты недоступны.

#### Scenario: JavaScript отключён

- **WHEN** страница открыта с отключённым JavaScript
- **THEN** видны все находки, предупреждения и блок рецензии, а панель фильтров
  не показывается

### Requirement: Автономность и безопасность

HTML MUST не ссылаться на внешние ресурсы и MUST NOT выполнять сетевых
запросов. Все динамические строки MUST экранироваться, а CSP MUST запрещать
внешние источники.

#### Scenario: Вредоносная строка в рубрике

- **WHEN** заголовок или детали находки содержат `<script>` или
  `"><img onerror=...>`
- **THEN** эти символы выводятся как текст и не исполняются

### Requirement: Проверка пути `--html`

Путь MUST проверяться после валидации входа, но до чтения рубрики и аудита.
Отчёт MUST NOT создаваться, если путь пуст, указывает на каталог или symlink,
родительская папка отсутствует или расширение не `.html`/`.htm`.

#### Scenario: Ранний отказ

- **WHEN** передан путь `/no-such-dir/report.html`
- **THEN** аудит не запускается, файл не создан, stderr содержит
  `ОТКАЗ: HTML-отчёт не записан — <причина>`, код возврата 2

### Requirement: Атомарная запись

Запись SHALL быть атомарной: временный файл в той же папке, `fsync`,
`os.replace`, права `0600`. При ошибке записи временный файл MUST удаляться,
а прежний файл MUST оставаться нетронутым.

#### Scenario: Ошибка записи

- **WHEN** `os.replace` завершается ошибкой
- **THEN** stdout уже содержит отчёт аудита, stderr — сообщение об ошибке,
  код возврата 2, целевой файл отсутствует или не изменён

### Requirement: Вердикт и деградация рецензии

HTML SHALL различать коды 0/1/2 текстом и оформлением. Недоступная рецензия
MUST показываться отдельным бейджем и MUST NOT менять баллы и вердикт.

#### Scenario: Рецензия недоступна

- **WHEN** запрошена рецензия, но endpoint недоступен
- **THEN** HTML создан, содержит «Рецензия недоступна» и текст ошибки,
  код возврата 3, баллы не изменились

#### Scenario: Ошибка записи важнее рецензии

- **WHEN** одновременно недоступна рецензия и не удаётся записать HTML
- **THEN** код возврата 2

### Requirement: Детерминированный вывод

Одинаковый отчёт MUST давать байт-идентичный HTML: без времени генерации,
случайных значений и скрытых находок.

#### Scenario: Два запуска подряд

- **WHEN** дважды генерируют отчёт на одной папке
- **THEN** `cmp` двух файлов не находит различий
