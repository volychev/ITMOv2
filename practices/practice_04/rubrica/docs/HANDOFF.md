## Ограничения

- Рубрика проверяет наличие файлов, а не их смысл. Пустой `reflection.md`
  аудит примет — это осознанное решение, см. `docs/RUBRIC-MAP.md`.
- Символические ссылки не обходятся, файлы больше 2 МБ и не-UTF8 помечаются
  как непроверяемые, а не как «правило пройдено».
- Внешние сервисы (Context7, GitHub MCP) не подключены: для задачи хватает
  собственного MCP и чтения локальных файлов.
- Установлен opencode 1.18.30, а не 2.0.20 из презентации. Hook написан под
  API 1.18.30 (`"tool.execute.after"` в возвращаемом объекте плагина), при
  переходе на 2.x его надо переписать — расхождение описано в `docs/HOOK.md`.
- Таймаут зависимости по умолчанию 10 с; учебный VseLLM при холодном старте
  в него не укладывается. Деградация отрабатывает корректно, но для успешного
  прогона нужен `--timeout 120`.

## Куда идти дальше

1. Поднять умолчательный таймаут зависимости до 30–60 с.
2. Добавить `file_contains` на `reflection.md`, чтобы рубрика проверяла
   наличие конкретных разделов, а не только файла.
3. Вынести проверку связности зависимости в отдельный вызов MCP
   (`rubrica_audit --check-narrative`), чтобы проверять её без токенов.
4. Переписать hook под API opencode 2.x, когда версия обновится.
